🔌 Connexion Moodle

🔑 Token web service Moodle (reste dans ton navigateur)

Crée ton token dans Moodle : Profil → Préférences → Clés de sécurité → « Moodle mobile web service ». Colle-le ici : il est stocké uniquement dans ce navigateur (localStorage) et n'est envoyé qu'à moodle.psl.eu, jamais ailleurs. Ne le partage avec personne. Tu peux le révoquer à tout moment dans Moodle.

🔄 Synchronisation automatique

Récupère tes cours inscrits, tes devoirs Moodle (avec dates de rendu) et les événements de ton calendrier Moodle. Ils apparaîtront sur ton emploi du temps et dans tes deadlines.

📥 Import calendrier (.ics) — sans token

Dans Moodle : Calendrier → Exporter le calendrier, copie l'URL .ics. Colle-la ici, ou importe directement le fichier .ics téléchargé.
